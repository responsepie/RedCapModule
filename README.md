# ResponsePie for REDCap

This REDCap External Module loads ResponsePie on every public survey page in
an enabled REDCap project. Researchers do not need to add JavaScript to
individual instruments or fields. One generic module can be installed on a
REDCap server and used by any project that has valid ResponsePie embed code.

## How it works

The researcher first copies the REDCap Public Survey Link from **Survey
Distribution Tools** and submits it on the ResponsePie website. ResponsePie
then provides a project-specific one-line JavaScript embed code.

The researcher pastes the complete line into the project's ResponsePie External
Module settings. The code is not added to a survey question, field, instrument,
or Survey Queue. The module validates it and automatically loads it on every
public survey page in that project.

The RP website supplies a line in this form:

```html
<script type="text/javascript" src="https://responsepie.com/redcap/deadcafe007.js" data-study-token="deadcafe007.js" integrity="sha384-Li9vy3DqF8tnTXuiaAJuML3ky+er10rcgNR/VqsVpcw+ThHmYcwiB1pbOxEbzJr7" crossorigin="anonymous></script>
```

The script is loaded only on public survey pages. It is not loaded on the
Online Designer, project-management pages, reports, or authenticated data-entry
forms.

## Installation

Installation requires a REDCap administrator.

1. Upload or copy the `response_pie_redcap_v1.4.1` folder into REDCap's
   `modules` directory.
2. In the REDCap Control Center, open **Manage External Modules** and enable
   **ResponsePie for REDCap**.
3. Open the REDCap project and select **Manage External Modules**.
4. Enable **ResponsePie for REDCap** for the project.
5. Select **Configure** beside the module.
6. Paste the complete one-line JavaScript embed code supplied by ResponsePie.
7. Save the module settings and test the survey using its public survey link.

## How to obtain the REDCap Public Survey Link

Before using the ResponsePie website, the REDCap instrument must be enabled as
a survey.

1. Open the relevant project in REDCap.
2. In the left navigation menu, select **Online Designer**.
3. Locate the instrument that participants will complete.
4. If the instrument is not already a survey, select **Enable** under **Enabled
   as survey** and configure its survey settings.
5. Return to the project menu and locate the **Survey Distribution Tools**
   section. In some REDCap versions, you may first need to select the survey
   name under **Data Collection** and then select **Survey Distribution
   Tools**.
6. Select the survey whose link will be distributed to participants.
7. Find the **Public Survey Link** section.
8. Select **Copy** beside the URL, or highlight and copy the complete URL.
9. Paste this URL into the REDCap integration page on the ResponsePie website.

Use the Public Survey Link rather than a link copied from the browser while
previewing or editing the survey. The Public Survey Link normally contains
`surveys/?s=` followed by the survey's unique public identifier. Menu names and
locations may vary slightly across REDCap versions and institutional
configurations. If **Survey Distribution Tools** is unavailable, the
researcher may need survey-management permission from the REDCap administrator.

## Researcher workflow

1. In the REDCap project, enable the intended instrument as a survey.
2. Open **Survey Distribution Tools** for the survey.
3. Copy the **Public Survey Link**.
4. Paste the Public Survey Link into the REDCap integration page on the
   ResponsePie website.
5. Copy the complete one-line JavaScript embed code generated by ResponsePie.
6. In REDCap, open **Applications** and then **External Modules**. Depending on
   the REDCap installation, the link may instead be called **Manage External
   Modules**.
7. Find **ResponsePie for REDCap** and select **Configure**.
8. Paste the complete line into **ResponsePie one-line JavaScript embed code**.
9. Save the module settings.
10. Open the survey using its Public Survey Link and submit a test response.

The module does not generate, store, or ask the researcher to extract a token.
It accepts the full line supplied by ResponsePie. For security, it verifies
that the line is an external script hosted at `studies.surveyproctor.com` and
then reconstructs the script element from the validated URL and attribute.

The configured embed code loads on every survey instrument in that REDCap
project. A different REDCap project can use the same installed module with its
own RP embed code.

## Verification

Open the survey's public link, then use the browser's developer tools:

1. Open the **Network** panel.
2. Reload the survey.
3. Search for `surveyproctor` or the study token.
4. Confirm that the JavaScript request returns a successful response.
5. Complete a test response and confirm that it appears in ResponsePie.

## Administrator notes

- The REDCap server must be able to serve survey pages that reference
  `https://studies.surveyproctor.com`.
- If the institution uses a Content Security Policy, the administrator may
  need to allow this domain under the applicable script and connection
  directives.
- Enabling the module without valid RP embed code does not inject the script.
- The study token is visible in the participant's page source because the RP
  browser script requires it. It should be treated as a study identifier, not
  as a secret credential.
- Test the module in a REDCap development or staging environment before
  production use.

## Compatibility

- REDCap 10.0.0 or later
- PHP 7.2 or later
- External Module Framework 14 or later

The module uses REDCap's `redcap_survey_page_top` hook.
